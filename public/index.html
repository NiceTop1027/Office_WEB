웹에서 바로 문서 편집

ONLYOFFICE Community + Express 조합으로 HWP/HWPX/PDF/Office 파일을 브라우저에서 열고, 저장 콜백으로 서버 파일까지 동기화합니다.

업로드 후 바로 `편집 열기`를 누르면 웹 에디터가 실행됩니다.

오픈소스 스택

  • ONLYOFFICE Document Server (AGPL)
  • Node.js + Express + Multer (MIT)
  • Tabler UI style system (MIT)
